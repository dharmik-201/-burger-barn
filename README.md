# Burger Barn — Demo

Burger Barn is a clearly fictional restaurant website created for portfolio purposes. It is not affiliated with any real business.

## Experience

- Interactive 3D burger, shake, and fries presentation
- Responsive menu, gallery, and fictional sample reviews
- Deep crimson, milkshake cream, cheddar, and charcoal visual system
- Private owner dashboard for gallery image management
- Person-free AI-generated food and restaurant imagery
- `noindex, nofollow` metadata for portfolio-only sharing

All names, addresses, reviews, imagery, and brand details shown on the public website are fictional.
